# local-data-integrity Specification

## Purpose

定义本地训练数据（`localStorage` 键 `gym4.db.v1`）在读取、校验、写入、导入四个环节的完整性契约：结构异常的历史记录与草稿不得让任何页面崩溃，写盘失败必须如实反馈且不丢数据。

## Requirements

### Requirement: 结构异常的本地数据不得让页面崩溃
系统 SHALL 在读取本地数据后过滤掉结构不可用的历史记录与草稿，使记录页、训练页、进度页在任何本地数据形态下都能完成渲染，不得因数据缺字段而抛出未捕获异常。跨标签页同步路径同样 SHALL 跳过结构不可用的记录，不得因一条坏记录中断数据合并。

#### Scenario: 历史记录的动作缺 sets
- **WHEN** 本地存储中存在某条历史记录，其动作缺少 `sets` 数组
- **THEN** 记录页与进度页正常渲染，该记录不进入历史列表与统计，并显示「N 条记录格式异常已跳过」的提示

#### Scenario: 历史记录的 sets 元素为 null
- **WHEN** 本地存储中存在某条历史记录，其某个动作的 `sets` 数组里含 null 元素
- **THEN** 记录页与进度页正常渲染，该记录不进入历史列表与统计，并计入「格式异常」提示

#### Scenario: 草稿的动作 sets 元素为 null
- **WHEN** 本地存储中存在某份草稿，其某个动作的 `sets` 数组里含 null 元素
- **THEN** 记录页正常渲染，坏草稿被清理且不显示在「未完成的训练」里，打开训练页不抛出异常

#### Scenario: 草稿缺少 moves
- **WHEN** 本地存储中存在缺少 `moves` 的草稿
- **THEN** 记录页正常渲染，该草稿被清理，不留下既看不见也删不掉的僵尸草稿

#### Scenario: 全部记录不可用时进度页说明原因
- **WHEN** 本地存在历史记录，但没有任何一条被进度页采用（全部结构异常，或全部训练日期晚于今天）
- **THEN** 进度页正常渲染，并说明存在因格式异常被跳过的记录或没有可统计的记录，不得只显示「还没有数据」

#### Scenario: 记录数组里含 null 元素且另一个标签页写入
- **WHEN** 本地存储的记录数组里含 `null` 元素，此时另一个标签页写入了本地数据
- **THEN** 本标签页不抛出未捕获异常，仍然把对方新增的可用记录并入内存并给出提示

### Requirement: 无可用记录时仍可导入备份
系统 SHALL 在进度页没有任何可用记录（本地库为空，或全部记录因结构异常、日期晚于今天而被过滤）时，仍然提供导入备份的入口，使恢复备份不依赖先产生一条本地记录。空态不要求提供导出入口。导入成功后进度页 SHALL 按导入后的数据重新渲染。

#### Scenario: 清缓存或换设备后导入备份
- **WHEN** 本地库为空时用户打开进度页
- **THEN** 页面显示空态并提供一个导入备份的入口，用户可选择 JSON 文件完成导入，导入后统计与图表按备份数据渲染

#### Scenario: 记录全部不可用时导入备份
- **WHEN** 本地存在记录，但全部因结构异常或日期晚于今天而未被进度页采用
- **THEN** 进度页同样提供导入备份入口，导入后按备份数据渲染

### Requirement: 存储容器结构异常时退化为空集合
系统 SHALL 校验本地数据中 `sessions` 与 `drafts` 的容器类型；类型不符时按空集合处理并继续启动，不得让页面在渲染时抛错。

#### Scenario: sessions 不是数组
- **WHEN** 本地存储中的 `sessions` 是对象而非数组
- **THEN** 计划页、记录页、进度页均能完成渲染，不出现未捕获异常

#### Scenario: drafts 不是对象
- **WHEN** 本地存储中的 `drafts` 是字符串而非对象
- **THEN** 记录页正常渲染，不出现未捕获异常

### Requirement: 写盘失败必须如实反馈且不丢数据
系统 SHALL 在写入本地存储失败时保留原有数据、向用户提示失败，并且不把失败的操作显示为成功。该约束 SHALL 覆盖所有会改动本地数据并写盘的路径：完成训练、删除记录、放弃草稿、导入数据、记录页渲染时的草稿清理。

#### Scenario: 完成训练时配额已满
- **WHEN** 写入本地存储抛出异常
- **THEN** 显示「存储失败」提示，训练页保持打开，本次训练不计入历史记录，用户可稍后重试

#### Scenario: 删除记录时写盘失败
- **WHEN** 删除某条历史记录后写入本地存储失败
- **THEN** 该记录回到删除前的状态，不显示删除成功的提示

#### Scenario: 记录页清理草稿时写盘失败
- **WHEN** 记录页渲染时清理了空草稿或结构损坏的草稿，随后写入本地存储失败
- **THEN** 显示「存储失败」提示，草稿容器回到清理前的状态，界面按回滚后的列表渲染（被清理的草稿重新出现，不得出现「磁盘上有、界面看不见」的状态），且不提示任何成功

### Requirement: 导入数据必须先校验后写盘
系统 SHALL 在导入 JSON 前校验其结构，校验不通过时拒绝导入、不改动现有数据、不写盘。导入前的覆盖确认 SHALL 说明现有记录与草稿都会被替换。

#### Scenario: 导入结构非法的数据
- **WHEN** 导入的 JSON 中 `sessions` 不是数组，或某条记录缺 `id`、`date` 格式不对、动作缺 `sets`，或 `rir`/`maxPain`/`durationMin` 不是数字
- **THEN** 显示失败原因并说明是哪一项不合法，现有记录保持不变

#### Scenario: 导入结构合法的数据
- **WHEN** 导入的 JSON 通过全部结构校验且用户确认覆盖
- **THEN** 现有记录与草稿被替换，进度页重新渲染并提示导入成功

#### Scenario: 覆盖确认说明草稿也会被替换
- **WHEN** 用户触发导入并看到覆盖确认
- **THEN** 确认提示里说明现有记录与草稿都会被替换，而不只提到记录

### Requirement: 导入必须拒绝重复的记录 id
系统 SHALL 在导入校验时检查 `sessions` 中记录 `id` 的唯一性；存在重复 `id` 时拒绝导入、不改动现有数据、不写盘。

#### Scenario: 导入含重复 id 的数据
- **WHEN** 导入的 JSON 中两条记录的 `id` 相同
- **THEN** 显示失败原因说明存在重复的记录 id，现有记录与草稿保持不变

#### Scenario: 导入 id 全部唯一的数据
- **WHEN** 导入的 JSON 通过其余全部结构校验且所有记录 `id` 互不相同
- **THEN** 校验通过，按既有导入流程进入确认与写盘环节

### Requirement: 多个标签页的写入不得互相覆盖
系统 SHALL 在检测到另一个标签页写入了本地数据时，把对方新增的训练记录合并进当前标签页的内存数据，使本标签页随后的任何写盘都不会丢掉对方刚写入的记录。合并 SHALL 保留本标签页正在编辑的草稿。

#### Scenario: 训练中另一标签页完成训练
- **WHEN** 用户在标签页 A 训练中，标签页 B 完成一次训练并写入本地存储
- **THEN** 标签页 A 提示另一标签页改动了数据，且把 B 刚写入的记录并入内存；A 后续的输入落盘后，B 的记录仍存在于本地存储中

#### Scenario: 另一标签页新增草稿
- **WHEN** 用户在标签页 A 训练中，标签页 B 为另一个训练日创建了草稿
- **THEN** 标签页 A 正在编辑的草稿内容不被 B 的草稿替换，A 退出训练后自己的草稿仍可按原内容继续

#### Scenario: 空闲时另一标签页删除记录
- **WHEN** 标签页 A 不在训练中，标签页 B 删除了一条记录
- **THEN** 标签页 A 同步到删除后的数据并重绘当前页面，被删除的记录不再出现在列表与统计中

### Requirement: 多个标签页的草稿不得互相覆盖
系统 SHALL 在检测到另一个标签页写入本地数据时，把对方新增的草稿并入当前标签页的内存数据，使本标签页随后的任何写盘都不会把对方尚未完成的训练抹掉。并入 SHALL 保留本标签页正在编辑的那份草稿内容不被替换。

#### Scenario: 训练中另一标签页新建的草稿不被本标签页落盘抹掉
- **WHEN** 用户在标签页 A 训练中，标签页 B 为另一个训练日新建了带内容的草稿，A 随后触发一次写盘（输入防抖、切后台或退出训练）
- **THEN** 标签页 B 的草稿在本地存储中仍然存在且内容不变，标签页 A 自己的草稿也仍然存在

#### Scenario: 本标签页正在编辑的草稿不被对方的草稿替换
- **WHEN** 用户在标签页 A 训练中，标签页 B 为同一个训练日与日期新建了草稿
- **THEN** 标签页 A 正在编辑的草稿内容不被替换，A 退出训练后自己的草稿仍可按原内容继续

#### Scenario: 空闲时另一标签页新建的草稿仍然可见
- **WHEN** 用户在标签页 A 不在训练中，标签页 B 新建了草稿
- **THEN** 标签页 A 同步后记录页的「未完成的训练」里出现该草稿，用户可继续它

### Requirement: 导入校验拒绝非法的草稿计时字段
系统 SHALL 在导入 JSON 前校验草稿的计时字段：已累计时长与计时起点必须是数字或缺省。校验不通过时拒绝导入、不改动现有数据、不写盘。

#### Scenario: 导入含非数字草稿计时字段的数据
- **WHEN** 导入的 JSON 中某份草稿的已累计时长或计时起点是字符串之类的非数值
- **THEN** 显示失败原因说明是哪一项不合法，现有记录与草稿保持不变
