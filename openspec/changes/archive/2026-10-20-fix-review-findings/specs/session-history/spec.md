# Spec Delta

## ADDED Requirements

### Requirement: 详情、编辑与删除以所选记录本身为准
系统 SHALL 以用户选中的那条记录本身来定位详情、编辑与删除操作，不以 `id` 匹配结果为准；本地存储中存在重复 `id` 时，单条操作 SHALL 只影响被选中的那一条记录。

#### Scenario: 点击重复 id 记录中的一条查看详情
- **WHEN** 本地存储中存在两条 `id` 相同的记录，用户点击历史列表中靠后的那一条
- **THEN** 弹层展示的是被点击的这一条记录的数据（日期、组数、容量与其列表行一致）

#### Scenario: 删除重复 id 记录中的一条
- **WHEN** 本地存储中存在两条 `id` 相同的记录，用户确认删除其中一条
- **THEN** 只有被选中的那一条被删除，另一条仍保留在列表与统计中

#### Scenario: 编辑重复 id 记录中的一条
- **WHEN** 本地存储中存在两条 `id` 相同的记录，用户编辑并保存其中一条
- **THEN** 只有被选中的那一条被更新，另一条保持原内容

### Requirement: 编辑有修改时离开页面必须给出提示
系统 SHALL 在用户编辑历史记录并做出修改后，于刷新、关闭或离开页面时触发浏览器原生的离开确认；未进入编辑、或编辑期间未做任何修改时 SHALL 不触发该提示。

#### Scenario: 编辑做过修改后刷新或关闭页面
- **WHEN** 用户编辑某条记录并修改了任意字段（重量、次数、勾选状态、RIR、疼痛、备注）后刷新或关闭页面
- **THEN** 浏览器弹出原生离开确认，提示更改可能不会保存

#### Scenario: 未修改或未进入编辑
- **WHEN** 用户未进入编辑，或进入编辑后没有修改任何字段就离开
- **THEN** 离开页面时不弹出离开确认
