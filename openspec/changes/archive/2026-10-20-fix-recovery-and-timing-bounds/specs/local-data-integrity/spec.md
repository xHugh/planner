# Spec Delta

## ADDED Requirements

### Requirement: 无可用记录时仍可导入备份

系统 SHALL 在进度页没有任何可用记录（本地库为空，或全部记录因结构异常、日期晚于今天而被过滤）时，仍然提供导入备份的入口，使恢复备份不依赖先产生一条本地记录。空态不要求提供导出入口。导入成功后进度页 SHALL 按导入后的数据重新渲染。

#### Scenario: 清缓存或换设备后导入备份

- **WHEN** 本地库为空时用户打开进度页
- **THEN** 页面显示空态并提供一个导入备份的入口，用户可选择 JSON 文件完成导入，导入后统计与图表按备份数据渲染

#### Scenario: 记录全部不可用时导入备份

- **WHEN** 本地存在记录，但全部因结构异常或日期晚于今天而未被进度页采用
- **THEN** 进度页同样提供导入备份入口，导入后按备份数据渲染

## MODIFIED Requirements

### Requirement: 结构异常的本地数据不得让页面崩溃

系统 SHALL 在读取本地数据后过滤掉结构不可用的历史记录与草稿，使记录页、训练页、进度页在任何本地数据形态下都能完成渲染，不得因数据缺字段而抛出未捕获异常。

#### Scenario: 历史记录的动作缺 sets

- **WHEN** 本地存储中存在某条历史记录，其动作缺少 `sets` 数组
- **THEN** 记录页与进度页正常渲染，该记录不进入历史列表与统计，并显示「N 条记录格式异常已跳过」的提示

#### Scenario: 历史记录的 sets 元素为 null

- **WHEN** 本地存储中存在某条历史记录，其某个动作的 `sets` 数组里含 null 元素
- **THEN** 记录页与进度页正常渲染，该记录不进入历史列表与统计，并计入「格式异常」提示

#### Scenario: 草稿的动作 sets 元素为 null

- **WHEN** 本地存储中存在某份草稿，其某个动作的 `sets` 数组里含 null 元素
- **THEN** 记录页正常渲染，坏草稿被清理且不显示在「未完成的训练」里，打开训练页不抛出异常

#### Scenario: 草稿缺少 moves

- **WHEN** 本地存储中存在缺少 `moves` 的草稿
- **THEN** 记录页正常渲染，该草稿被清理，不留下既看不见也删不掉的僵尸草稿

#### Scenario: 全部记录不可用时进度页说明原因

- **WHEN** 本地存在历史记录，但没有任何一条被进度页采用（全部结构异常，或全部训练日期晚于今天）
- **THEN** 进度页正常渲染，并说明存在因格式异常被跳过的记录或没有可统计的记录，不得只显示「还没有数据」
